Bizout é uma plataforma online que conta com mais de 800 mil questões de concursos para resolução, desenvolvida com foco em leveza, simplicidade e design moderno.

O projeto utiliza MariaDB como banco de dados SQL, GoLang para a API no backend e Vue+Vite/Nuxt/Node.js para a camada de front-end, garantindo rotas otimizadas para SEO com SSR — como em https://bizout.com.br/qst_id/{id}, permitindo que questões únicas sejam facilmente indexadas pelo Google Search.

Entre as funcionalidades implementadas, destacam-se:

    Marcadores: sistema de filtros que permite salvar buscas e identificar quais questões já foram resolvidas.
    
    Estatísticas de desempenho: histórico e métricas diárias por marcador, ajudando no acompanhamento do progresso.
    
    Login funcional: com gerenciamento de dispositivos, alteração de senha e personalização de perfil com imagem.
    Sessões de usuário: controladas de forma segura e eficiente utilizando Redis.
